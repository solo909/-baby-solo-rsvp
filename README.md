# Baby Solo RSVP

A mobile-friendly baby shower invitation for Steven and Brillana Solorzano, designed for GitHub Pages.

## RSVP email setup

The form uses [FormSubmit](https://formsubmit.co/) and sends responses to `Steven-444@live.com`.

1. Make one test RSVP after the website is live.
2. FormSubmit will email `Steven-444@live.com` an activation message.
3. Open that email and click **Activate Form**.
4. Submit the test RSVP again to confirm delivery.

No FormSubmit account or paid plan is required. The first activation email is an anti-spam step.

## GitHub Pages

In the repository settings, open **Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. The site URL will be:

`https://solo909.github.io/baby-solo-rsvp/`
